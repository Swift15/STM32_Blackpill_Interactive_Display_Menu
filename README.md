# STM32\_Blackpill\_Interactive\_Display\_Menu

this little project show how to create a interactive menu using stm32, lcd1306 with lib and 4 keys keyboard.





!\[Under Construction](https://img.shields.io/badge/status-under--construction-yellow)



This little project shows how to use an STM32 with an OLED Display working with the Adafruit SSD1306 LIB





1 - Choose microcontroller

2 - config pins 

3 - download display lib

4 - test config between display and LCD using ssd\_1306 library

5 - add keyboard 

6 - test keyboard 

7 - add menu functions
